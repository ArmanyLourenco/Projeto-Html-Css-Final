# Nova Era — Landing Page (Projeto) - MMORPG

Breve descrição: Meu projeto consistem em uma Página de apresentação (landing page) para o MMORPG fictício chamado "Nova Era". É um jogo online (MMORPG) com mundo aberto e personalização total do personagem.

Como resolvi cada ponto :

Identidade do jogo: O projeto deixa claro que Nova Era é um MMORPG online com servidores persistentes e interação entre jogadores. Veja o título e a meta description em index.html.

Personalização do personagem: Destaquei nos CTAs e nas features que os jogadores podem criar e personalizar seus personagens livremente. O botão "Criar personagem" leva ao formulário de inscrição/entrada na beta.

Features relevantes para MMO: Atualizei as descrições das features: servidores persistentes, progressão/RPG, e customização total.

Arquivos principais atualizados:

index.html
styles.css
assets/hero.svg

10 tópicos solicitados:
1. Estrutura Semântica Rigorosa

A página foi desenvolvida utilizando elementos semânticos do HTML5, como <header>, <nav>, <main>, <section>, <article>, <aside> e <footer>. Essa organização melhora a estrutura do código, a acessibilidade e a compreensão do conteúdo pelos mecanismos de busca.

2. Design System com Variáveis CSS

Foi criado um sistema de design utilizando variáveis CSS definidas no seletor :root. As cores, tipografia, espaçamentos e demais propriedades visuais foram centralizadas, garantindo consistência visual e facilitando futuras manutenções.

3. Layout Híbrido (Grid e Flexbox)

O projeto utiliza CSS Grid e Flexbox de forma complementar. O Grid foi aplicado na organização das principais seções da página, como a área de destaque (Hero) e a seção de recursos (Features), enquanto o Flexbox foi utilizado para alinhamento de elementos menores, como menus, botões e formulários.

4. Interface Responsiva

A landing page foi desenvolvida seguindo a abordagem Mobile First, priorizando inicialmente dispositivos móveis e utilizando media queries com min-width para adaptar o layout a telas maiores. Também foi implementado um menu responsivo para garantir a navegação em smartphones e tablets.

5. Microinterações e Animações

Foram adicionadas animações suaves de entrada e efeitos de interação (hover e focus) em botões e elementos da interface. Essas microinterações tornam a navegação mais agradável e fornecem feedback visual ao usuário.

6. Curadoria de Código com IA

Ferramenta de Inteligência Artificial foi utilizadas como apoio durante o desenvolvimento do projeto, auxiliando na revisão do código HTML e CSS, na implementação de boas práticas de acessibilidade, na otimização da responsividade e na identificação de melhorias estruturais. Todas as sugestões foram analisadas e adaptadas manualmente. A IA utilizada neste contexto foi o ChatGPT

7. Dark Mode Nativo

O projeto possui suporte nativo aos modos claro e escuro por meio da media query prefers-color-scheme. As variáveis de cores são alteradas automaticamente de acordo com a preferência do sistema operacional do usuário, garantindo melhor experiência visual.

8. Sticky Header e Scroll Snap

Foi implementado um cabeçalho fixo utilizando position: sticky, permitindo que o menu permaneça visível durante a navegação. Além disso, foi utilizado o recurso Scroll Snap para proporcionar uma transição mais suave entre as seções da página.

9. Performance e Otimização de Assets

Foram aplicadas práticas de otimização, como carregamento tardio de imagens (loading="lazy"), correção de referências de arquivos, remoção de recursos inválidos e organização dos ativos do projeto. Essas medidas contribuem para um carregamento mais rápido e eficiente da página.

10. Acessibilidade Avançada

Foram implementados recursos de acessibilidade, incluindo link de salto para o conteúdo principal (Skip Link), indicadores visuais de foco (:focus-visible), atributos ARIA, formulários com rótulos associados e navegação por teclado. Essas práticas tornam o site mais acessível e inclusivo para diferentes perfis de usuários.
